## Sobre

O Projeto Jano reúne ferramentas de código aberto projetadas para execução local, sem dependência de serviços em nuvem. Cada projeto é acompanhado de código comentado e documentação em português, com o objetivo de servir tanto como ferramenta de uso quanto como material de estudo.

Responsável: **Victor H. Correa**

---

## Projeto principal: Aprendiz

Assistente pessoal local e offline, que responde exclusivamente com base no conhecimento fornecido pelo próprio usuário. Não coleta dados, não acessa a internet e foi projetado para operar inclusive em máquinas com poucos recursos.

### Algoritmos implementados

| Técnica | Finalidade |
|---|---|
| BM25 | Ranqueamento de documentos por relevância |
| TF-IDF | Ponderação de termos |
| Naive Bayes | Classificação de intenção |
| Distância de Levenshtein | Tolerância a erros de digitação |
| Reciprocal Rank Fusion (RRF) | Combinação de resultados de múltiplas buscas |
| TextRank | Extração e sumarização de trechos relevantes |

## Princípios

1. **Execução local** — os dados permanecem na máquina do usuário.
2. **Transparência** — código legível, comentado e documentado.
3. **Acesso livre** — uso, estudo e modificação gratuitos.
